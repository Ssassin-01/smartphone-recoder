# Smartphone Recorder (스마트폰 녹화 앱)

영리하고 직관적인 프리미엄 스마트폰 녹화 어플리케이션입니다.

## ✨ 주요 기능
- **고화질 화면 녹화**: 내부 시스템 소리와 마이크 소리를 동시에 녹음합니다.
- **플로팅 컨트롤러**: 다른 앱 사용 중에도 화면 위에 떠 있는 버튼으로 자유롭게 녹화를 제어할 수 있습니다.
- **프리미엄 UI**: 다크 모드와 글래스모피즘 기반의 세련된 디자인을 제공합니다.
- **실시간 타이머**: 녹화 중 경과 시간을 실시간으로 확인할 수 있습니다.

## 🛠 기술 스택
- **Framework**: Flutter
- **State Management**: Riverpod (Notifier)
- **Packages**:
  - `flutter_screen_recording`: 녹화 엔진
  - `flutter_overlay_window`: 플로팅 제어 버튼
  - `permission_handler`: 권한 관리

## 🚀 시작하기
1. 레포지토리를 클론합니다.
2. `flutter pub get` 명령어로 의존성을 설치합니다.
3. 안드로이드 기기를 연결하고 `flutter run`으로 실행합니다.
